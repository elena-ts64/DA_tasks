возьмете для дальнейшей работы и что будете с ней делать?\

Перед финальным принятием модели проверю, что не перепутаны метки лошадь и пони, что положительный класс определён правильно, что отсутствует утечка данных в тестовой выборке.

ROC-AUC = [число пар, где s+ > s−] / (n+ * n-)

n+ - число объектов положительного класса = 7\
n- - число объектов отрицательного класса = 8\
s+ - score модели для положительного объекта: [0.95, 0.85, 0.75, 0.70, 0.65, 0.60, 0.40]\
s- - score модели для отрицательного объекта: [0.90, 0.80, 0.55, 0.50, 0.45, 0.35, 0.30, 0.25]

Для каждого положительного объекта выполняю подсчёт количества объектов отрицательного класса со значением score ниже:

## Решение

Среднее число выпитых чашек кофе = (1+1+2+2+2+2+3+3+3+4) / 10 = 2,3\
Среднее значение балла = (85+88+79+81+84+65+67+58+76+49) / 10 = 73,2

∑(xi - xср) * (yi - yср) = -93,6

√(∑(xi - xср)^2 * ∑(yi - yср)^2) ≈ 110,21234

Линейный коэффициент корреляции Пирсона:\
r = -93,6 / 110,21234 ≈ -0,84926969

## Ответ
**Линейная корреляция Пирсона:**
`-0,85`

Между числом выпитых чашек кофе и баллом за экзамен наблюдается сильная отрицательная линейная корреляция: в этой выборке большее число чашек кофе связано с меньшим баллом.

Но корреляция не доказывает причинность. По этим данным нельзя утверждать, что кофе снижает результат: например, больше кофе могли пить студенты, которые сильнее устали или хуже подготовились.
