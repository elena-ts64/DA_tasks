# Задание 1: Фермер 

## Описание задачи

На ферме содержатся шесть разных видов животных, и каждый раз, когда фермер заходит в сарай, он видит одно случайное животное. За день фермер заходит в сарай 6 раз. 

Каково математическое ожидание количества разных видов животных, которые фермер увидит за день?\
<i>Примечание: Ответ округлить до сотых, например: 4,12</i>

## Решение:

Пусть X – кол-во увиденных видов животных\
Ii – индикатор встречи каждого вида\
Ii = 1, если вид i был замечен хотя бы раз, иначе 0

Мат. ожидание X = сумме мат. ожиданий индикаторов\
E(X) = E(I1) + E(I2) + E(I3) + E(I4) + E(I5) + E(I6)

Для конкретного вида вероятность не увидеть его ни разу за 6 посещений = (5/6)^6\
Тогда вероятность увидеть этот вид хотя бы один раз = 1 - (5/6)^6\
Значит для 6 видов E(X) = 6 * (1 - (5/6)^6) ≈ 3,99

## Ответ:
**Математическое ожидание количества уникальных видов животных:**  
`3,99`

# Задание 2: Кулинарное соревнование

## Описание задачи
В конкурсе участвуют 80 шеф-поваров с уникальными уровнями мастерства. В первом этапе судьи случайным образом распределяют их по парам (в любом состязании двух шефов выигрывает тот, у кого выше уровень мастерства). На втором этапе шефы снова случайно образуют пары для финального раунда (пары могут повториться). Победную награду получают те, кто выиграл в обоих этапах.

Каково математическое ожидание числа победителей?\
<i>Примечание: Ответ округлить до десятых, например: 33,5</i>

## Решение:

Пусть X – кол-во шев-поваров, победивших в обоих этапах\
E(X) = 80 * P(шеф выиграл оба этапа)

Для 1 из 80 шефов вероятность выигрыша в 1 этапе зависит от его уровня мастерства:\
P(победа в одном этапе) = число слабейших соперников / общее число соперников\
P(победа в одном этапе) = k / 79, где k – рейтинг шефа от 0 до 79

Тогда для 2 независимых этапов вероятность равна произведению вероятностей:\
P(победа в двух этапах) = (k / 79)^2, где k – рейтинг шефа от 0 до 79

Для каждого возможного значения k есть ровно один шеф. Поэтому математическое ожидание числа победителей:\
E(X) = Σ от k=0 до 79 (k / 79)^2\
Σ от n=0 до 79 k^2 = n * (n + 1) * (2*n + 1) / 6 = 79 * 80 * 159 / 6\
E(X) = 79 * 80 * 159 / (6 * 79^2) = 80 * 159 / (6 * 79) ≈ 26,835443

## Ответ:
**Математическое ожидание числа победителей:**  
`26,8`

# Задание 3: Одинокая дорога

## Описание задачи

На пустынном шоссе вероятность появления автомобиля за 30-минутный период составляет 0.95.

Какова вероятность его появления за 10 минут? А за 27 минут?\
<i>Примечание:Ответ дать в процентах, округлив до десятых через точку с запятой, например: 42,7; 95,0</i>

## Решение

По формуле Пуассона вероятность того, что событий не произойдёт (k = 0): P0(t) = e^(-λ * t)\
Вероятность появления хотя бы одного события: P_(≥1)(t) = 1 - P0(t) = 1 - e^(-λ * t)

Найдём интенсивность λ по заданным условиям:\
P(30) = 1 - e^(-λ * 30) = 0,95\
e^(-λ * 30) = 0,05\
λ = -ln(0.05) / 30 ≈ 0,0998577 - интенсивность событий в минуту

Вероятность появления автомобиля хотя бы 1 раз за 10 минут:\
P(10) = 1 - e^(-λ * 10) = 1 - e^(-0,0998577 * 10) ≈ 1 - 0,3684 ≈ 0,6316 → 63,2%

Вероятность появления автомобиля хотя бы 1 раз за 27 минут:\
P(27) = 1 - e^(-λ * 27) = 1 - e^(-0,0998577 * 27) ≈ 1 - 0,0675 ≈ 0,9325 → 93,3%

## Ответ:
**Вероятность появления автомобиля за 10 минут; за 27 минут:**  
`63,2; 93,3`
